# Carly Woods Sample Business Brain

The public companion repository for *The Great AI Bullshit Filter* by Carly Woods.

This is a **fictional example**, not Carly's real business brain. It shows how to give AI useful business context without handing it passwords, banking details, client records or sensitive information.

## Use this sample

1. Click **Use this template** at the top of this repository.
2. Create a new repository under your GitHub account.
3. Set your new repository to **Private**.
4. Work through [START-HERE.md](START-HERE.md).
5. Replace the fictional examples with accurate information about your business.
6. Delete anything you do not need.

## Included

- a completed fictional business example
- blank templates
- a documented process
- brand voice and output examples
- a one-page AI policy
- standing instructions that keep the brain current

## The rule

Useful context belongs here. Secrets do not.

Never add passwords, API keys, banking details, identity documents, private client information, health information or confidential employee records.

Companion to the [Great AI Bullshit Filter Toolkit](https://link.carlywoods.ai/toolkit).
