# Security Rules

This repository is public because it contains a fictional example. Your real business brain should be private.

## Never store

- passwords, recovery codes, API keys or access tokens
- banking or payment card details
- identity documents
- private customer or employee records
- health, legal or financial case information
- confidential contracts
- data you do not have permission to use

Write the rule, not the secret.

Bad: "The bank password is..."

Good: "Payments require finance approval and must use the approved banking platform."

Before connecting AI, confirm what the tool can read, change and share. Grant the smallest access required.
